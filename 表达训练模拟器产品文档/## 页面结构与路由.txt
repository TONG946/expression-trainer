## 页面结构与路由

/                      首页：今日训练入口 + 三场景入口 + 最近记录
/train/[sceneType]     训练页：对话模拟主界面
/replay/[sessionId]    复盘页：复盘小结
/history               历史记录：所有训练会话 + 个人语料库

## 首页布局

1. 今日训练卡片（最显眼）：显示“今日训练”标题、三个场景的轮换状态、大按钮「开始训练」。
2. 三个场景入口卡片：幽默感 / 结构化表达 / 高情商回复，每个显示场景名、一句话说明、已练次数。
3. 最近训练记录（最多 5 条）：显示场景类型、时间、轮数、一句话复盘摘要。
4. 底部导航：首页 / 历史。

今日训练推荐逻辑：
- 读取 localStorage 中最近 3 次训练的场景类型
- 推荐最近最少练的那个场景
- 如果无记录，默认推荐「高情商回复」

## 训练页状态机

[加载中] → [生成场景] → [对话中] → [结束点判断] → [自然结束提示] → [复盘]
                            ↑                              ↓
                            └────── 用户选继续 ────────────┘

加载中：显示“正在生成场景…”，调用 /api/generate-scene 生成场景卡 + 人设卡 + 对方首句。

## /api/generate-scene

方法：POST
请求体：{ "scene_type": "humor | structured | eq", "recent_scenes": ["主题1", "主题2"] }
响应：{ "scene_card": { SceneCard } }
逻辑：调用硅基流动 API，使用场景生成器 Prompt，temperature=1.0（增加多样性）。

## 场景生成器 Prompt 输出要求

幽默感场景：
- 情境：日常交友聊天中的某个瞬间
- 对方首句：一个自我贬低、吐槽、或抛出话题的句子
- 人设：普通朋友，有自己情绪，接梗率 0.3-0.7
- 训练目标：练习“接受+叠加”的接话结构

结构化表达场景：
- 情境：工作汇报/演讲/口播的某个具体场景
- 对方首句：一个追问、打断、或要求说明的句子
- 人设：听众/上级/客户，时间有限，注意力分散
- 训练目标：练习“结论先行”或“框架选择”

高情商回复场景：
- 情境：面对不友好/敌意/吵架的具体场景
- 对方首句：一个攻击性、质疑、或情绪化的句子
- 人设：带着情绪和立场来的人，不轻易让步
- 训练目标：练习“非防御性回应”或“安全感修复”

## localStorage Schema

Key 命名规范：etm_ 前缀

etm_sessions = TrainingSession[]
etm_corpus = CorpusItem[]
etm_last_recommendation = { date: '2026-09-12', scene_type: 'eq' }

存储操作封装在 /lib/storage.ts：
saveSession / getSessions / getSessionById / saveCorpusItem / getCorpus / getRecentScenes / getRecommendedScene

容量控制：最多保留 100 条 session，超出时删除最早的。
