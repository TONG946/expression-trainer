## 理论库配置

humor:
- yes_and: Yes, and 原则 / 即兴喜剧 / 先接受对方抛出的设定，再往上叠加新信息。不要否定对方的前提。 / 对方自我贬低、吐槽、抛出话题时
- surprise_link: 意外关联 / 《笑点》 / 在两个看似无关的事物之间建立关联，制造意外感。 / 需要制造笑点时
- self_deprecation: 自嘲 / 《笑点》 / 把攻击性转向自己，降低对方防御，同时制造反差。 / 对方调侃你、或气氛紧张时
- exaggeration: 夸张 / 《笑点》 / 把某个特征或情境放大到荒诞的程度，制造喜剧效果。 / 描述日常琐事时

structured:
- pyramid: 金字塔原理 / 芭芭拉·明托《金字塔原理》 / 结论先行，分层表达。让听众第一时间知道你要说什么。 / 工作汇报、演讲
- conclusion_first: 结论先行 / 《金字塔原理》 / 开口第一句就是结论，而不是过程。 / 所有结构化表达场景
- mece: MECE 原则 / 《金字塔原理》 / 相互独立、完全穷尽。信息分类时不重叠、不遗漏。 / 信息归类时
- scqa: SCQA 框架 / 《金字塔原理》 / 情境-冲突-疑问-答案。先用情境和冲突牵引注意力，再给出答案。 / 需要先建立共识再给方案的场景
- prep: PREP 框架 / 通用表达框架 / 观点-理由-案例-观点。口头表达的简洁闭环。 / 听众已知背景，只想知道方案时

eq:
- nvc_observation: 观察 vs 评论 / 马歇尔·卢森堡《非暴力沟通》 / 说“你今天迟到了10分钟”是观察，说“你总是迟到”是评论。评论会触发防御。 / 对方用评论攻击你时
- nvc_feeling: 表达感受而非攻击 / 《非暴力沟通》 / 说“你这么说让我有点措手不及”是感受，说“你行你上”是攻击。 / 被冒犯时
- nvc_request: 具体化请求 / 《非暴力沟通》 / 把“你能不能靠谱点”换成“能不能具体说一两点最关键的问题”。 / 需要对方配合时
- key_conversation_safety: 安全感维护 / 《关键对话》 / 当对话失去安全感时，先修复安全感，再推进内容。 / 对方情绪激烈、对话升级时
- boundary: 边界表达 / 通用心理学 / 在维护关系的同时维护自己。不讨好，也不攻击。 / 面对持续施压时
