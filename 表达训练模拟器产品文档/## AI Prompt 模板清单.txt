## AI Prompt 模板清单

所有 Prompt 集中在 /lib/prompts.ts，包含 4 个模板：

1. SCENE_GENERATOR_PROMPT：场景生成器，输入 scene_type + recent_scenes，输出 JSON 格式 SceneCard。
2. CHAT_PROMPT：对话生成器，输入 scene_card + history + scene_specific_constraints，输出 AI 回应文本。
3. JUDGE_END_PROMPT：结束点判断器，输入场景信息 + 对话历史，输出 JSON 格式 EndJudgment。
4. REPLAY_PROMPT：复盘生成器，输入 session + end_judgment + theory_library，输出 JSON 格式 ReplaySummary。

每个 Prompt 的完整内容见产品文档第六节。其中 CHAT_PROMPT 包含三个场景专属约束块（幽默/结构化/高情商），必须原样保留，特别是“反讨好硬规则”部分。

CHAT_PROMPT 中的场景专属约束块：
- 幽默场景：接梗率不高于 50%，可以不接梗、转移话题、说“有点尬”。
- 结构化场景：听众时间有限，会追问“结论呢？”“你要我做什么？”，不夸奖。
- 高情商场景：不会因为一句“我理解你”就缓和，单轮情绪降温不超过 0.3，可以说“你这话说了等于没说”。
